# Options Trainer (Options Dojo)

A single-file options trading simulator for learning. Open `index.html` in any browser — no install needed.

- Black-Scholes pricing with volatility skew, bid/ask spreads and fees
- Live option chain, Greeks, and profit/loss charts
- Earnings events with IV crush
- Daily "coach" log that explains your P&L (delta, gamma, theta, vega)
- Guided tutorial, 11 missions, and a Learn tab
- Bright and dark themes

All money is fake. This is an educational tool, not financial advice.
